为什么这里要收

  • 侧边 gutter 不足 104px，按钮硬放会盖住正文（现在代码用 min() 夹取，就是这个后果）
  • 翻页改由底部章节导航和 ← / → 承担，不损失能力
  • 按钮保留文案但压缩内边距；再窄可退化为 40×40 图标
