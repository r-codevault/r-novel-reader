# 小说阅读器 (Novel Reader)

一个 VS Code 小说阅读插件：导入本地 `.txt` 小说，自动解析章节目录，在侧边栏生成可点击跳转的章节列表，并提供沉浸式阅读界面。

## 功能特性

- **导入本地 txt 小说**
  - 命令面板 / 侧边栏按钮打开文件，资源管理器右键 `.txt` 文件亦可直接打开
  - 自动识别文件编码：UTF-8（含 BOM）、UTF-16LE/BE、GB18030（中文小说站点下载文件常见）
- **智能章节目录解析**
  - 识别 `第X章` / `第X节` / `第X回` / `第X卷` / `第X部` / `第X篇`（阿拉伯数字与中文数字均可）
  - 识别 `序章`、`楔子`、`引子`、`尾声`、`终章`、`后记`、`番外篇` 等特殊章节
  - 识别英文 `Chapter 12` / `Vol.3` 格式
  - 自动剔除正文中缩进重复出现的标题、`(本章完)` 结尾标记以及疑似目录页
- **章节目录树**
  - 侧边栏「小说阅读」容器展示全部章节，点击即跳转阅读
  - 当前阅读章节高亮（眼睛图标），并自动滚动定位
  - 有阅读进度时置顶「继续阅读」入口
- **阅读界面**
  - 阅读区位于编辑器区域，支持章节下拉框快速跳转、上一章/下一章按钮、`Alt+←` / `Alt+→` 快捷键
  - 顶部进度条显示整书阅读进度
- **个性化阅读偏好（自动保存）**
  - 字体大小（12–32px，支持 A- / A+ 快捷按钮）
  - 字体族：系统默认 / 宋体 / 黑体 / 楷体 / 仿宋 / 微软雅黑
  - 行距（1.2–2.8）、段距（0–2em）、阅读宽度（480–1200px）
  - 主题配色：米黄纸 / 护眼绿 / 纯净白 / 简约灰 / 暗夜 / 墨黑
  - 所有偏好通过 `globalState` 持久化；也可在 VS Code 设置页（搜索 `novelReader`）修改默认值，两处实时同步
- **阅读进度记忆**
  - 自动保存最近文件、当前章节与章内滚动位置，重启 VS Code 后可从侧边栏「继续阅读」一键回到原位置

## 快速开始

### 直接安装打包好的 vsix

```bash
code --install-extension novel-reader-1.0.0.vsix
```

### 开发调试

```bash
npm install
npm run compile
```

随后在 VS Code 中打开本项目，按 `F5` 启动扩展开发宿主，在调试窗口中：

1. 点击左侧活动栏「小说阅读」图标
2. 点击目录树顶部的「打开小说文件」按钮（或命令面板执行 `小说阅读器: 打开小说文件`）
3. 选择 `.txt` 小说文件即可开始阅读

### 打包

```bash
npx @vscode/vsce package
```

## 使用说明

| 操作 | 方式 |
| --- | --- |
| 打开小说 | 侧边栏 `+` 按钮 / 命令面板 / 右键 txt 文件 |
| 跳转章节 | 点击侧边栏章节、阅读页顶部下拉框、上一章/下一章按钮 |
| 调整阅读设置 | 阅读页右上角「Aa 设置」 |
| 继续上次阅读 | 侧边栏「继续阅读」条目 / 命令面板 `小说阅读器: 继续阅读` |
| 刷新目录 | 侧边栏刷新按钮（文件内容更新后使用） |

## 项目结构

```
novel-reader/
├── package.json            # 插件清单(命令/视图/配置贡献点)
├── tsconfig.json
├── src/
│   ├── extension.ts        # 入口: 命令注册、文件加载、编码识别、进度恢复
│   ├── novelParser.ts      # 章节目录解析器
│   ├── chapterProvider.ts  # 侧边栏章节目录树
│   ├── readerPanel.ts      # 阅读界面 Webview(章节渲染 + 设置面板)
│   └── settings.ts         # 阅读偏好(主题/字体定义 + globalState 持久化)
├── scripts/make-icon.js    # 图标生成脚本
└── media/                  # 图标资源
```

## 已知限制

- 仅支持纯文本 `.txt`（不支持 epub/mobi 等二进制格式）
- 编码识别基于 BOM 与 UTF-8 校验启发式，极端混合编码文件可能需先用编辑器另存为 UTF-8
